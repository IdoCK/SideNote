# Native screenshot provenance

The published native images are Compose-root captures with fictional test states on an Android API 37 Pixel 8 emulator, captured 2026-09-17. They omit Android system UI. They are not browser reconstructions, photographs or physical-device acceptance evidence.

- `native-review.webp`: captured from the corrected local 1.0.12/code13 Review source, using the synthetic multi-date ReviewScreenTest fixture. September 5 is selected; September 8/10 remain plain text. Lossless WebP from the native PNG, 1080 × 2400.
- `native-settings.webp`: captured from the 1.0.12/code13 debug ReviewNavigationTest configured-state fixture, using fictional folder/test configuration. Lossless WebP from native output.

Both images were retained for version 1.0.13/code14 because that release changed version metadata only and the depicted native UI was unchanged. Neither is represented as a fresh 1.0.13 capture. Current manifest entries retain represented version, original capture distinctions, image classification and checksums.

The manifest also separately labels browser captures (`capture.webp`, `review.webp`), generated/staged illustrations (`hero.webp`, `thumbnail.webp`) and gesture illustration (`face-down.png`). These are not native evidence. This public snapshot preserves the existing image bytes; no new native screenshots or physical-device claims are made.
