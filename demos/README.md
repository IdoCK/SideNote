# SideNote visual demo

Open [`sidenote-demo.html`](./sidenote-demo.html) in a modern browser. The file is self-contained and requires no build step or network connection.

The desktop presentation includes a screen picker for Capture, Dates, Projects, Settings, and first-run setup. The interaction panel simulates the native app's power-button/screen-off, face-down, repeated Quick Tap, and spoken project-tag signals. These controls demonstrate UI states only; browsers cannot reproduce Android microphone, sensor, keyguard, Storage Access Framework, or Pixel Quick Tap behavior.

At phone widths the presentation chrome disappears and the selected app screen fills the viewport.
